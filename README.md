# 🚀 LogicFlow: Smart Task Prioritizer

LogicFlow is a smart, algorithm-driven command-line tool designed for students to logically prioritize their daily tasks, assignments, and exam preparation based on deadlines and task complexity. 

Built for the **Galgotias Logic League**.

## ✨ Key Features
- **Smart Sorting Logic:** Ranks tasks based on Urgency Score (Deadline proximity + Complexity).
- **Fast & Lightweight:** Pure CLI-based tool with zero lag.
